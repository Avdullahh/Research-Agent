# Used briefs — archive only

Filled-in research briefs whose report PDF has been **approved** by the user.

## For agents: do not read this folder

This is a record, not an input. Never read, glob, or search these files when starting a
new research task, and never use their contents as context for one.

Each research task gets its guidelines fresh from a new brief. That is the entire premise
of the workflow — carrying a previous task's credibility rules, region, role lens, or
theme into a new one silently corrupts the next report.

The blank template lives at `workflows/brief_template.md` and stays there permanently.

## Naming

`YYYY-MM-DD-<topic-slug>.md`, matching the `run_id` of the report it produced, so a brief
can be traced back to its PDF in `output/` and its working files in `.tmp/`.
